Data in your profile

Copy the app anywhere and run it. Your data lives in your Windows profile, so it survives replacing the app with a newer one.

Downloads\
  Shiftbook.exe
C:\Users\you\AppData\Roaming\
  Shiftbook\
    shiftbook.db     (encrypted)
    vault.json
    backups\

Data next to the app

Everything in one folder, so it can live on a USB stick or a synced folder. Turned on by a file named portable beside the app.

E:\Shiftbook\
  Shiftbook.exe
  portable
  data\
    shiftbook.db     (encrypted)
    vault.json
    backups\
