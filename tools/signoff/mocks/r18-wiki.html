Replacing a stack member

Edited 2 Nov · 4 earlier versions · in Network

How to swap a failed member out of a switch stack without taking the rest down. For the change itself, start a MOP from Change (MOP) on the ticket.

Before you go

  1. Check the stack's firmware: the new unit must match (Firmware upgrade if not).
  2. Save the running config: copy run start
  3. Note which member number failed: show switch

On site

  1. Power the failed member off, keep the stack cables in.
  2. Swap the unit, same slot, same cables.
  3. Power on and wait for it to join:
show switch
show switch stack-ports summary

If it comes up as a new member number, see Port security basics before moving ports.
